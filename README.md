The safety warning label that should come printed on every human being's snooze button.

`main.py` (Python 3.13, stdlib only, deterministic, no network, no randomness) writes exactly one original warning label — a single line of 96 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> WARNING: Pressing snooze nine times does not make you rested, it makes you late with confidence.

The joke: everyone knows the snooze button is a trap, and the label says it out loud — nine presses buy no rest at all, only a confident kind of lateness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
